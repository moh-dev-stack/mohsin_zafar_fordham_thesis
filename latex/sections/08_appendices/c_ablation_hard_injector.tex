Three things change and one does not.

\begin{itemize}[leftmargin=1.4em, itemsep=0.15em]
  \item \textbf{The analyte code becomes essential.} The injected values are now clinically adjacent,
        and a generic envelope cannot separate them from real readings.
  \item \textbf{The unit becomes more valuable}, 33.60 pp against 28.04, for the same reason.
  \item \textbf{The control rises} from 0.9851 to 0.9944, because the hard injector cannot write a
        physiologically real value and call it a defect, so the false ground truth of
        Section~\ref{sec:benchmark} largely disappears.
  \item \textbf{Both zero rows stay at zero.}
\end{itemize}
