\textbf{The harder task produces the higher score.} F1 rises in five cells and never falls. On
MIMIC-IV at seed 45 it goes from $0.9615$ to $1.0000$. That looks backwards until the cause is named,
and Section~\ref{sec:benchmark} names it.

\begin{itemize}[leftmargin=1.4em, itemsep=0.15em]
  \item \textbf{The legacy injector was manufacturing false ground truth.} It draws uniformly from four
        constants, and when it draws $9999$ the analyte may be one whose own bound in the rule file
        admits $9999$. The eICU aggregate code pools creatine
        kinase with the transaminases and inherits the widest of their bounds, which admits $9999$.
        The checker is right not to flag those, and the benchmark counts it as a miss.
  \item \textbf{The hard injector cannot do this.} It reads the analyte's own bound and places the
        value outside it, so every injected defect is a genuine defect by construction.
  \item \textbf{The residual $0.9831$ on eICU-CRD is not an injection artefact.} It is the single real
        corrupt record, the body temperature of $99.8^\circ$C discussed in
        Section~\ref{sec:benchmark}, correctly flagged and scored as a false positive.
\end{itemize}

So the hard injector both makes the task hard enough to rank detectors and removes a source of false
ground truth from the ground truth itself.
